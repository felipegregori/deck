Política de Privacidade · QG Manager Agente GTA6

Em vigor desde 14 de novembro de 2026

Resumo

O QG Manager Agente GTA6 é uma ferramenta pessoal, usada apenas pelo criador do canal Agente GTA6 para acompanhar as estatísticas do próprio canal. Ela só lê dados, roda no computador do criador e não vende, não compartilha e não envia esses dados para nenhum servidor nosso ou de terceiros.

Quem usa este app

O app não é oferecido ao público. Ele é usado exclusivamente pelo dono do canal Agente GTA6, na própria conta do Google, para ver números do canal em um painel no seu computador.

Uso dos YouTube API Services

Este app usa os YouTube API Services (YouTube Data API, YouTube Analytics API e YouTube Reporting API). Ao usar o app, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google segue a Política de Privacidade do Google.

Quais dados o app acessa

Com a autorização do dono da conta, o app pede ao Google apenas permissões de leitura:

  • youtube.readonly — ver as informações do canal e a lista de vídeos (título, data de publicação, duração e miniatura).
  • yt-analytics.readonly — ver as estatísticas do canal e dos vídeos (visualizações, tempo assistido, retenção, inscritos ganhos e perdidos, curtidas, comentários, compartilhamentos, fontes de tráfego, impressões e taxa de cliques).

O app não consegue publicar, editar ou apagar vídeos, comentar, alterar o canal, acessar dados financeiros, e-mails ou senhas. Ele não acessa dados de espectadores individuais: as estatísticas do YouTube Analytics são números agregados.

Como os dados são usados

Os dados servem somente para mostrar gráficos e indicadores (como retenção, taxa de cliques e evolução de inscritos) no painel local do criador, para ele entender o desempenho dos próprios vídeos. Não há publicidade, criação de perfis, venda ou compartilhamento de dados.

Onde os dados ficam e por quanto tempo

  • Os dados vão diretamente dos servidores do Google para o computador do criador. Não existe servidor intermediário.
  • A autorização de acesso fica guardada criptografada no computador do criador (proteção de dados do Windows).
  • As estatísticas ficam salvas localmente nesse computador enquanto o criador usar o app, e são atualizadas a cada poucas horas. Ao remover o app e seus arquivos, os dados são apagados.

Como cancelar o acesso

O acesso pode ser revogado a qualquer momento nas configurações de segurança da conta do Google: myaccount.google.com/permissions (também em security.google.com/settings/security/permissions). Depois de revogado, o app não consegue mais ler nenhum dado.

Mudanças e contato

Se esta política mudar, a data no topo desta página será atualizada. Dúvidas: entre em contato pelo canal Agente GTA6 no YouTube.
